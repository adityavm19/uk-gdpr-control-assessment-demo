# Processor Security Review

## Scope and sample
Population: five material processors appearing in selected processing activities. Judgemental sample: `MT-TP-001` Microsoft, `MT-TP-003` ServiceNow and `MT-TP-010` Northbridge CRM Services Ltd.

## Test attributes
- risk-based due diligence supports the controller's decision that the processor provides sufficient security guarantees;
- contract includes security obligations aligned to Article 28(3) and Article 32 outcomes;
- subprocessor and incident/rights assistance obligations are documented;
- ongoing assurance is refreshed proportionate to risk;
- identified assurance issues are tracked to closure.

## Result
Contractual design was adequate in all three selected files. Microsoft and ServiceNow had current assurance records. Northbridge's annual security review was overdue and a prior penetration-test action had no closure evidence. This operating-effectiveness exception is reported as `GDPR-FND-004` / `MT-TPR-001`.

Evidence: `MT-EV-517`, `MT-EV-518`.
