# Processor security assurance Workpaper

**Workpaper ID:** MT-WP-512  
**Test ID:** MT-TST-512  
**Control / process:** GDPR-CTL-012  
**Evidence:** MT-EV-517;MT-EV-518

## Objective
Material processors provide sufficient security guarantees, contracts include required security obligations, and assurance is refreshed proportionate to risk.

## Population and sampling
Population: 5 material processors in selected ROPA activities. Sample: 3 processors: MT-TP-001, MT-TP-003, MT-TP-010. Rationale: Judgemental sample covers critical cloud, privacy workflow and customer CRM processing.

## Procedure
Reviewed design documentation and source evidence; reconciled the stated population; tested selected attributes; investigated deviations; distinguished design from operating effectiveness.

## Evidence sufficiency
Evidence was considered relevant, timely for the assessment period and corroborated beyond inquiry. Where system-generated evidence was unavailable or incomplete, that limitation is reflected in the conclusion.

## Result
Partial - Northbridge annual security assurance was overdue and an earlier penetration-test action lacked closure evidence.

## Conclusion
Design: Effective. Operating effectiveness: Partially Effective. Exception MT-EXC-504 supports GDPR-FND-004.
